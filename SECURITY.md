# Security policy

## Scope of this repository

This is a **showcase repository**. It contains documentation, synthetic demo content and a curated excerpt of source code. It does **not** contain:

- credentials, API keys, tokens or signing material,
- production configuration, hostnames or infrastructure identifiers,
- client presentations, meeting recordings, transcripts or any other production data,
- installers or build artifacts.

All presentation, knowledge and Session examples are synthetic and built around the fictional company "Northstar Retail".

The SevenAI security architecture is described in [docs/security.md](docs/security.md).

## Reporting a concern

If you believe something in this repository is sensitive, or you have found a security issue in the architecture it describes:

1. **Preferred:** use GitHub's **private vulnerability reporting** ("Report a vulnerability" under the repository's Security tab).
2. **Otherwise:** open a GitHub issue that states only that you would like to report a security concern. **Do not include exploit details, credentials or sensitive data in a public issue.** A maintainer will arrange a private channel.

Please allow reasonable time for a response before any public disclosure.
